## Что в файлах

Серия — JSON скрипта как есть (`Series` в `src/measure.ts`): версия Chrome и Node, флаги Chrome,
сжатие (`transport`), адреса файлов статики с версиями (какая сборка измерена), отпечаток данных,
все прогоны всех частей. Ни паролей, ни cookie, ни ключа от ворот, ни данных людей в них нет:
только тестовый двор и показания браузера. Проверено перед сохранением.

Отличия от файлов, которые записал скрипт:

- **`m13.json` собран из двух запусков.** Первый (13:24) остановился на восьмом прогоне музыки:
  `fetch failed` — скрипт прочитал файл порта DevTools, пока Chrome его ещё писал (исправлено в
  26e893a). Из первого взяты загрузки и путь, из второго (14:42) — музыка и память.
- **`a-93950a1.json` собран из трёх запусков.** Первый (26.11 15:27) — загрузки; путь прервал сон
  компьютера с закрытой крышкой. Второй (27.11 05:07) — путь; музыку прервал тот же сбой порта
  DevTools. Третий (05:48) — музыка и память.
- **`a-memory-150.json`** снят копией скрипта, которая проходит 150 кругов вместо 50 и делает
  снимки кучи на 50-м и 150-м кругах (снимки не сохранены: по 5–10 МБ). Отчёт его не читает; это
  проверка роста кучи, см. `docs/m14-prototype-a.md`, «Память».

Серии 93950a1 — до исправления утечки (b0b2747): в их памяти растут узлы, и порог памяти они не
проходят. Загрузки и путь от исправления не зависят.
